# CampusConnect Placement Portal

Production-oriented prototype for student industry placement management at Gaborone Business College (GBC).

Includes responsive Next.js UI, role-based prototype experiences, opportunities, applications, placements, reporting, synthetic data, Microsoft 365 integration documentation, Scrum/product documentation and a target Prisma model.

Prototype integrations are not connected to a live tenant. The demo role selector is not a security boundary; production authorization must be enforced server-side.

Run locally with npm install, then npm run dev. Open http://localhost:3000.
