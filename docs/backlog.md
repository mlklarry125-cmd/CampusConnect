# Product Backlog — CampusConnect

The master product package defines 13 in-scope user stories delivered across four two-week Scrum sprints. The first increment prioritises the student journey; later increments add employer, coordinator, supervisor, reporting and governance workflows.

## Sprint 1
US-01 identity/profile; US-02 browse opportunities; US-03 submit and track applications.

## Sprint 2
US-04 employer profile/opportunity management; US-05 review applications; US-06 employer workflow actions.

## Sprint 3
US-07 placement lifecycle; US-08 supervisor assignment/progress; US-09 employer feedback; US-10 notifications/integration surfaces.

## Sprint 4
US-11 reporting; US-12 administration/reference data; US-13 audit/governance.

Acceptance criteria remain the source of truth for implementation. A screen is not complete merely because it renders.
