# Microsoft 365 Target Integration

## Entra ID
Target authentication is OAuth 2.0 Authorization Code with PKCE. Entra security groups map users to CampusConnect roles.

## Teams
Placement channels can become collaboration spaces with a CampusConnect tab and status notifications.

## Outlook
Graph-based notification email and placement calendar events are target capabilities.

## SharePoint/OneDrive
CVs and generated reports can be stored in controlled institutional libraries.

## Graph webhooks
Target webhook processing keeps relevant calendar, membership and file events synchronised.

These are target capabilities from the specification, not active integrations in this prototype. Tenant permissions and institutional approval are prerequisites.
