# Scrum Delivery Plan

## Sprint 1 — Foundation + student application
Goal: working shell plus identity/profile, opportunity discovery and application journey.

## Sprint 2 — Employer workflow
Goal: opportunity creation, application review and employer-side workflow.

## Sprint 3 — Placement supervision
Goal: placement lifecycle, supervisor actions, feedback and notifications.

## Sprint 4 — Reporting + governance
Goal: reporting, administration, auditability and production-readiness gates.

Each sprint ends with a reviewable increment, evidence, retrospective and backlog refinement.
